NusaStat — an independent national statistics site about Indonesia: sourced, dated figures for the country's people, economy and 38 provinces. Five linked pages (Overview, Economy, People, Provinces, Data & methods) with real BPS figures, SVG charts drawn from the data, a year picker, a province picker, sortable and searchable tables, and a phone layout. Static files only — no build step, no network requests, works offline on desktop and phone.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080/ — or serve `app/` with any static HTTP server.
